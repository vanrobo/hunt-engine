              Cryptic Guide
              
            
            
                                                
              
                                                Cryptic hunt playbook
                                                
              
                                                BOT / Paradigm-style OSINT — what to find, which direction, when to stop.
                                                

              
                                                

              
                                                The two questions (say out loud every hop)
                                                
              
                                                  
                
                                                1. What am I trying to produce right now?
                                                  2. 
                
                                                2. What evidence says this lane is live?
                                                  3. 
              
                                                

              
                                                

              
                                                Hunt flow mindmap
                                                
              
                                                NEW CLUE / ARTIFACT
        ↓
LEVEL NAME = theme compass (rose, voice, Folly…)
        ↓
WHAT OUTPUT TYPE?  ← most stalls happen here
        ↓
GIVEN only (file, page source, mod hint — not wiki essays)
        ↓
ONE action (one search OR one page OR one decode)
        ↓
VERIFY lane (mod rel? / teammate / theme fit)
        ↓
NEXT hop ──────────────┐
        or             │
SUBMIT answer          │
(lowercase, no spaces) │
        └──────────────┘
              (loop back to OUTPUT TYPE)
                                                
              
                                                Rules: Given beats derived · One hop = one output · Theme fit check
                                                

              
                                                

              
                                                At level start
                                                
              
                                                  
                
                                                •  Read level NAME (e.g. rose, voice) — not internal labels
                                                  • 
                
                                                •  List GIVEN artifacts: filename, URL, page HTML, Discord text
                                                  • 
                
                                                •  Name the ONE output type you need next (see table below)
                                                  • 
                
                                                •  Assign roles: feeder (tabs) + closer (types output, calls rel?)
                                                  • 
              
                                                

              
                                                Every hop (30s team sync)
                                                
              
                                                  
                
                                                •  We have: [paste artifact]
                                                  • 
                
                                                •  Next output is: slug / phrase / person / decode / ID / final
                                                  • 
                
                                                •  One try: single search OR one page OR one decode
                                                  • 
                
                                                •  Stop if: wrong theme, mod irrel, or merged two hops
                                                  • 
                
                                                •  Before submit: lowercase, no spaces, team confirms
                                                  • 
              
                                                

              
                                                

              
                                                Output types — pick ONE before you search
                                                
              
                                                
                
                                                
                  
                    
                                                
                      Type
                      You get…
                      Then you…
                      Example
                    
                                                
                                                                  
                  
                    
                                                
                      Backlink slug
                      /word path
                      Open hunt.site/slug, view-source
                      /redgod, /p47p52
                    
                                                
                    
                                                
                      Search phrase
                      Exact words to Google
                      Quote-search; not wiki essays
                      to the stars
                    
                                                
                    
                                                
                      Named entity
                      Person, org, title
                      Find their weird association
                      TTSA, Amy Eskridge
                    
                                                
                    
                                                
                      Decode
                      Hidden string
                      Use as next input, not decoration
                      HODOR cipher, Base64 highlight
                    
                                                
                    
                                                
                      Media artifact
                      Image/audio bytes
                      Decode first, match elsewhere
                      SSTV rabbit, morse.wav
                    
                                                
                    
                                                
                      Platform ID
                      Numeric/token ID
                      Open correct platform + feature
                      IG highlight, Genius ID
                    
                                                
                    
                                                
                      Structured extract
                      P/L/W/L, coords, barcode
                      Follow hunt rules exactly
                      book cipher, geohash
                    
                                                
                    
                                                
                      Final answer
                      lowercase, no spaces
                      Team confirm, then submit
                      echoesofyourname
                    
                                                
                                                                  
                
                                                
              
                                                

              
                                                Direction branches
                                                
              
                                                Last artifact → next tool
                                                
              
                                                
                
                                                
                  
                    
                                                
                      You have…
                      Go…
                    
                                                
                                                                  
                  
                    
                                                
                      Riddle / prose
                      Title or concept search
                    
                                                
                    
                                                
                      /slug page
                      View-source, audio, comments, /s/ paths
                    
                                                
                    
                                                
                      Cipher output
                      Exact phrase search (not Wikipedia rabbit hole)
                    
                                                
                    
                                                
                      Person / org
                      Niche wiki, credits, scandal — not generic bio
                    
                                                
                    
                                                
                      Media file
                      SSTV, spectrogram, metadata, LSB before guessing
                    
                                                
                    
                                                
                      Social token
                      Platform-specific (Song DNA, YT comments, IG highlight)
                    
                                                
                    
                                                
                      Filename
                      Often is the clue (oneword.mp4, I'm Deranged)
                    
                                                
                                                                  
                
                                                
              
                                                

              
                                                Kill a branch when…
                                                
              
                                                  
                
                                                • Mod says irrel
                                                  • 
                
                                                • Does not fit level NAME / theme
                                                  • 
                
                                                • You merged two hops (wiki + song + slug at once)
                                                  • 
                
                                                • Output type unclear — pause, don't open more tabs
                                                  • 
                
                                                • Generic popular page with no hunt-specific tie
                                                  • 
                
                                                • Platform front page with nothing hunt-specific (e.g. Travis Scott Spotify)
                                                  • 
              
                                                

              
                                                

              
                                                On every backlink page
                                                
              
                                                  
                
                                                •  View page source (Ctrl+U) — HTML comments, hidden /s/ paths
                                                  • 
                
                                                •  Reveal hidden layers / contrast / aria-hidden
                                                  • 
                
                                                •  Download linked media — check filename + extension
                                                  • 
                
                                                •  Run audio/image through SSTV, spectrogram, exiftool, steghide
                                                  • 
                
                                                •  Classify strings: Base64, cipher, geohash, snowflake, ISBN
                                                  • 
              
                                                

              
                                                Mod / team discipline
                                                
              
                                                  
                
                                                •  Ask rel? on the lane, not the answer
                                                  • 
                
                                                •  rel = keep going | rel but not final = right thread, wrong depth
                                                  • 
                
                                                •  irrel = kill branch immediately
                                                  • 
                
                                                •  Named /slug in hint = you need that backlink page
                                                  • 
                
                                                •  Paste concrete artifact when asking (URL, decode, theory)
                                                  • 
              
                                                

              
                                                

              
                                                Tool quick map
                                                
              
                                                
                
                                                
                  
                    
                                                
                      Signal
                      Tool / action
                    
                                                
                                                                  
                  
                    
                                                
                      Audio squeal / picture in audio
                      SSTV decode (QSSTV, MMSSTV)
                    
                                                
                    
                                                
                      Dots and dashes
                      Morse decode
                    
                                                
                    
                                                
                      Hodor-like repetition
                      HODOR cipher / dCode
                    
                                                
                    
                                                
                      eyJ… or /s/ path
                      Base64 decode
                    
                                                
                    
                                                
                      HTML empty page
                      View source, comments, zero-width
                    
                                                
                    
                                                
                      Image feels loaded
                      exiftool, steghide, strings, StegStruck
                    
                                                
                    
                                                
                      gcp… / u4pru…
                      Geohash decode
                    
                                                
                    
                                                
                      Long number in URL
                      Genius annotation, Discord snowflake, Scratch ID
                    
                                                
                    
                                                
                      TXT in DNS hint
                      dig / nslookup TXT record
                    
                                                
                    
                                                
                      Passworded paste
                      Try hunt themes; check filename hints
                    
                                                
                                                                  
                
                                                
              
                                                

              
                                                

              
                                                Team roles (Encore-style)
                                                
              
                                                Feeder opens tabs and drops links.
                                                
              Closer names the output type, runs the 30s sync, and calls mod rel? before the team burns time.
                                                
              One theory per hop until verified.
